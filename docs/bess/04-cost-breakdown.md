# 4. EPCC Cost Breakdown — Cost Components & Work Components

Basis: **100 MW / 400 MWh, base case RM 360 mil** (RM 900/kWh), 33 kV delivery, excluding interconnection (priced separately in doc 06). Percentages hold approximately across 25–200 MW.

## 4.2 Work component breakdown (execution packages)

| Package | Scope | Typical contracting |
|---|---|---|
| WP1 Engineering & studies | Basic + detailed design, grid studies (load flow, SC, stability, harmonics), protection settings, Bomba/PBT submissions | EPCC in-house / owner's engineer review |
| WP2 Procurement | Battery supply agreement (with capacity/degradation warranty ≥70 % @ yr 10, availability ≥97 %), PCS, transformers, switchgear, cables | EPCC; battery often owner free-issue on large projects |
| WP3 Civil works | Doc 02 scope | G7 civil subcontractor |
| WP4 Electromechanical installation | Skid setting, cabling, terminations, earthing, LPS | EPCC direct or M&E sub |
| WP5 Controls & integration | EMS/PPC, SCADA-to-GSO, metering | Specialist integrator |
| WP6 Testing & commissioning | Cold/hot commissioning, Grid Code compliance tests (P/Q capability, LVRT witness, frequency response), reliability run 30 days | EPCC + owner + TNB witness |
| WP7 Interconnection works | Doc 06 — PMU bay/LILO, substation, line/cable | Often TNB-nominated or TNB-approved contractor; wayleave by owner |

## 4.3 Payment & risk structure (typical Malaysian EPCC)

- Milestones: 10 % advance (bonded) / 60–70 % against delivery milestones (battery shipments dominate) / installation & commissioning balance / 5–10 % retention to PAC→FAC.
- LDs: delay LDs 0.5–1 % contract price per week (cap 10 %); performance LDs on usable energy, round-trip efficiency (≥85 % AC-AC typical) and availability.
- Battery price indexation window fixed at NTP; FX shared or hedged.
- Warranty: plant 24 months from PAC; battery capacity warranty separate (10 yr), backed by OEM directly to owner.
